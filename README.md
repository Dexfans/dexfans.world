# DexFans.world

Crypto creator platform built on Solana.

## Payments

DexFans currently supports:

- SOL
- GOJIPOWER

No other payment rails are enabled.

## Architecture

Frontend:

- HTML
- CSS
- JavaScript

Backend:

- Node.js
- Express

Database:

- SQLite

Blockchain:

- Solana
- SPL tokens
